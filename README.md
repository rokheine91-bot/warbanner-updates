# Warbanner

**Install:** download `installer/Warbanner-Setup_v<version>.zip`, unzip it and run `Warbanner-Setup.exe`.
It downloads the game, checks its signature, and installs it for your user (no administrator rights).
The game updates itself: when a new version is out it asks "Update now / Later".

This repository only holds the released game builds. It is replaced with every release.
